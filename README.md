# Estudos de GitHub Actions

Este repositório contém exemplos e experimentos com **GitHub Actions**, usados para aprender e praticar automação de CI/CD e desenvolvimento de pipeline.

## Objetivo meus com o curso
- Explorar conceitos básicos de workflows.
- Testar gatilhos (`on: push`, `on: pull_request`, etc.).
- Configurar jobs e steps com diferentes actions.
- Praticar integração contínua (CI) e deploy automatizado com ambientes reais mesmo de contexto simples.
