
# Estudos de GitHub Actions

Este repositório contém exemplos e experimentos com **GitHub Actions**, usados para aprender e praticar automação de CI/CD  especializando mais em DEVOPS E INFRA.

## Objetivo do curso :
- Explorar conceitos básicos de workflows.
- Testar gatilhos (`on: push`, `on: pull_request`, etc.).
- Configurar jobs e steps com diferentes actions.
- Praticar integração contínua (CI) e deploy automatizado.
